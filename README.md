# 生活手记（LifeLog）

一个**纯本地、零账号、无网络权限**的生活琐事记录器，用来回答一个问题：

> **「我上次做这件事，是什么时候？」**

理发、换床单、看病、洗牙、换滤芯、宠物驱虫……这些事没有固定日程，
但过一阵子总会想不起来具体日期。本应用让「随手记一笔」的成本低到没有借口，
并在你需要时（比如医生问「上次检查什么时候」）立刻给出答案。

---

## 快速开始

### 1. 编译 APK（不用装 Android Studio）

本项目已配置 GitHub Actions，推送代码后会自动编译：

1. 把代码推送到你的 GitHub 仓库
2. 打开仓库的 **Actions** 标签页
3. 等待编译完成（首次约 5-10 分钟，之后有缓存约 2 分钟）
4. 在页面底部的 **Artifacts** 区域点击 `生活手记-debug-apk` 下载
5. 传到手机安装

> 也可以手动触发：Actions 页面 → 右侧 `Run workflow`。

### 2. 安装

- Android 8.0（API 26）及以上
- 首次安装需允许「未知来源应用」
- **后续版本直接覆盖安装即可，数据不会丢失**（仓库里提交了固定的 debug 签名密钥）

## 功能

### 记录：四个入口，摩擦递减

| 入口 | 操作 | 说明 |
|---|---|---|
| 桌面小组件（列表型） | 点开应用 | 显示多个事件的距今天数 |
| 桌面小组件（单事件型） | **点一下即记** | 大字显示距今天数，点击直接记录 |
| 应用内「随手一点」栏 | 点一下即记 | 把常用事件钉选后出现在首页顶部 |
| 应用内卡片 ✓ 按钮 | 点一下即记 | 通用兜底入口 |

需要写备注、拍照、倒填日期时，用「带备注记」。

### 查看与决策

- 每张卡片大字显示**距今天数**，色条表示状态：
  - 🟢 还早（< 75% 间隔）｜🟡 快到了（75–100%）｜🔴 该做了（> 100%）
- **未设间隔的事件会自动学习**：记满两次后按你的历史平均节奏判断
- **预测下次日期**：基于实际节奏推算，不是拍脑袋的固定值
- 详情页：累计次数、平均间隔、最短间隔、完整时间线
- **全局时间线**：所有事件混在一起按时间倒序，回答「上个月我都干了些啥」
- **年度回顾**：一年理发 8 次、看病 3 次……一张卡片看完
- 全局搜索：搜事件名 + 备注全文（比如搜「血常规」翻出所有相关就诊）

### 数据安全

- 存在手机本地，**不申请网络权限**，无广告、无统计、无账号
- 每次修改后自动保留最近 4 份本地备份
- 支持导出：JSON（纯数据）/ ZIP（含照片，推荐）/ CSV（可用 Excel 打开）
- 支持导入：自动合并，不会覆盖已有数据

## 技术栈

| 项 | 选择 |
|---|---|
| 语言 | Kotlin 2.3.21 |
| UI | Jetpack Compose + Material 3 |
| 小组件 | Jetpack Glance 1.1.1 |
| 持久化 | JSON 文件（org.json）+ DataStore |
| 最低系统 | Android 8.0（API 26） |
| 编译目标 | API 36 |

**为什么不用 Room？** 个人生活琐事的数据量极小（几年通常也只有几百条），
全量读写 JSON 性能完全够用，同时省掉注解处理器，显著降低 CI 首次编译的失败概率。

**为什么不用 Coil/Glide？** 这些图片库会传递引入 OkHttp，
从而给应用带来不必要的网络相关依赖，与「零网络权限」的设计原则冲突。
照片加载直接用 `BitmapFactory` 实现，只有几十行代码。
