# 技术设计：使用说明

## 现状

应用里有几处信息没有解释，用户只能猜：

- 卡片色条（绿/黄/红/灰）代表什么
- 「判断基准」是什么，为什么有时是 30 天
- 「平均间隔」为什么不显示
- 倒填时间的入口藏在哪（这正是上一轮造成误解的原因）

## 方案

设置页新增「使用说明」入口，一个可滚动的静态页面，
内容分四块：状态色含义、基准的三级回退、四个入口的区别、数据在哪怎么备份。

## 取舍

- **不做新手引导弹窗**：首次启动时用户没耐心看，且是打扰
- **不做交互式教程**：维护成本高，容易随界面改动而失效
- **必须放进 App 里**：写进 README 没用，用的时候不会去翻 GitHub

## 关键风险

说明文案必须**跟着功能改**。将来改了状态阈值或加了新的记录入口，
要同步更新这份说明——否则它会变成错误信息，比没有说明更糟。

建议在相关 change 的 tasks.md 里，把「更新说明」列为收尾项。
