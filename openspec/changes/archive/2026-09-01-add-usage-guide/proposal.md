# 使用说明

## 对应需求

需求 3：图标不知道什么含义，希望有个说明。

## 为什么改

应用里有几处信息是**靠猜**的：

- 卡片左侧的色条（绿/黄/红）代表什么
- 状态文字「该做了 / 快到了 / 新鲜」是怎么算出来的
- 详情页统计块里的「判断基准」是什么，为什么有时候是 30 天
- 「平均间隔」为什么有时候不显示

这些如果不解释，用户就不知道该信到什么程度，
也不知道为什么某个事件突然变红了。

## 做什么

设置页加「使用说明」入口，内容分四块：

### 1. 状态色是什么意思

| 颜色 | 含义 | 触发条件 |
|---|---|---|
| 绿色 | 新鲜 | 距上次 < 基准的 75% |
| 黄色 | 快到了 | 距上次 ≥ 基准的 75% |
| 红色 | 该做了 | 距上次 ≥ 基准 |
| 灰色 | 待记录 | 还没有任何记录 |

### 2. 「基准」是怎么来的

三级回退，按顺序取第一个可用的：

1. 你给这个事件设的期望间隔
2. 历史平均间隔（记录满 2 条后自动算出）
3. 兜底 30 天

**重点解释第 2 条**：看病这类没规律的事，记满两次后
系统会自己学会你的节奏，不用你提前设定。

### 3. 四个入口的区别

| 入口 | 记什么 | 适用 |
|---|---|---|
| 桌面小组件 | 当前时间 | 高频项，最快 |
| 首页随手一点 | 当前时间 | 钉选的常用项 |
| 卡片 ✓ | 当前时间 | 通用 |
| 补录 | 你指定的时间 | 事后补记 |
| 带备注记 | 时间 + 文字 + 照片 | 需要留细节 |

### 4. 数据在哪、怎么备份

- 数据只在本机，不联网、不上传
- 设置页可导出 JSON / ZIP / CSV
- 每次写入自动保留最近 4 份本地备份
- **建议每月导出一次**，防止手机丢失或清缓存

## 不做什么

- ❌ 不做新手引导弹窗（打扰，且首次启动时用户没耐心看）
- ❌ 不做交互式教程（维护成本高，容易和界面改动脱节）
- ❌ 不写进 README 就完事——必须在 App 里能看到，
  因为用的时候不会去翻 GitHub
