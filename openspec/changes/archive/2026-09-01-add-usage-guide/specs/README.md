# 本 change 不产生 spec 变更

使用说明是**纯文档功能**，不改变系统行为，
因此不新增、不修改任何 Requirement。

按 OpenSpec 规范，这类改动只需 proposal / design / tasks，
不需要 delta spec。保留本文件是为了让归档目录结构完整，
并明确说明「没有 delta」是有意为之，而非遗漏。

## 但它有一条长期约束

`design.md` 中已写明：

> 说明文案必须跟着功能改。将来改了状态阈值或加了新的记录入口，
> 要同步更新这份说明——否则它会变成错误信息，比没有说明更糟。

这条约束落在 `specs/` 之外（属于维护约定而非系统行为），
因此体现为 `tasks.md` 中长期未勾选的第 3.1 项。
