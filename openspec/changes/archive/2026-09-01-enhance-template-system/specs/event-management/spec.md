# Delta for Event Management

> ⚠️ 本 delta 为事后补记，实际改动已直接应用到 `specs/`。

## ADDED Requirements

### Requirement: 模板入口可重复进入

系统 SHALL 在设置页提供常驻的模板导入入口，
**不得**只在空状态页提供。

#### Scenario: 用过一阵子后还想加模板

- **GIVEN** 用户已有 5 个事件
- **WHEN** 打开设置页的「模板」分组
- **THEN** 仍能看到全部内置模板并可继续导入

**理由**：首次启动时用户根本不知道自己会用到哪些模板，
让他在这个时刻一次性做完决定本身就是错的。

#### Scenario: 已存在的事件置灰

- **GIVEN** 「理发」已经存在
- **WHEN** 打开模板导入列表
- **THEN** 「理发」显示为已添加、不可勾选

### Requirement: 外部模板文件导入

系统 SHALL 支持导入外部 JSON 模板文件，`type` 字段为必填，
导入前展示预览、经确认后才写入。

#### Scenario: 文件类型不匹配

- **GIVEN** 用户选择了一份数据备份文件
- **WHEN** 解析
- **THEN** 明确提示「这是 XXX，不是模板文件」
- **AND** 不导入任何内容

**理由**：模板文件与数据备份文件都是 JSON，
没有类型标记就只能靠猜结构。
