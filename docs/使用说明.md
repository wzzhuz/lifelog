# 生活手记 · 使用说明

## 第一次打开

1. 打开应用，首页是空的
2. 点右下角 **＋**，或者点「从模板导入」
3. 模板里有 24 个常见事件，勾选你需要的（比如理发、换床单、看病）
4. 导入完成，首页就有卡片了

建议**先只建 5–8 个事件**。别一上来把生活全拆了，用顺了再加。

---

## 日常记录

### 最快的三种方式

| 场景 | 操作 |
|---|---|
| 桌面放了单事件小组件 | 直接点小组件 |
| 首页有「随手一点」栏 | 点一下那个事件 |
| 在卡片列表里 | 点卡片右下角的 ✓ |

这三种都只记「当前时间」，不写备注，一次点击完成。

### 需要写东西时

1. 点卡片进详情页
2. 点「带备注记」
3. 可以改时间（昨天理的发，今天补记就选昨天）
4. 写文字，需要的话加张照片
5. 保存

---

## 怎么设置「钉选」

把高频事件钉到顶部，它们会出现在首页的「随手一点」栏，点一下就记。

操作：进事件详情 → 右上角 ⋮ → 「钉到顶部」。

建议只钉 3–5 个，钉太多反而找不到。

---

## 桌面小组件

长按桌面空白处 → 小组件 → 找到「生活手记」：

- **列表型（4×2）**：显示最多 5 个事件和距今天数，点一下打开应用
- **单事件型（2×2）**：大字显示距今天数，**点一下直接记一笔**

单事件型添加时会让你选是哪一个事件。可以放多个，每个绑不同事件。

> 如果桌面天数更新不及时，打开一次应用就会刷新。
> 部分国产 ROM 会限制后台刷新，这是系统行为，不是应用故障。

## 理解卡片上的状态

卡片左边有一条竖着的色条：

| 颜色 | 状态 | 含义 |
|---|---|---|
| 🟢 绿 | 还早 | 距上次还不到你节奏的 75% |
| 🟡 黄 | 快到了 | 到了 75%–100% |
| 🔴 红 | 该做了 | 超过你的常规节奏了 |
| ⚪ 灰 | 待记录 | 还没记过 |

**判断基准从哪来？**

- 如果你给事件设了「期望间隔天数」→ 按这个算
- 如果没设 → 记满两次后按你的**历史平均间隔**自动算
- 一次都没记过 → 灰色「待记录」

所以「看病」这种没规律的事，不用提前设间隔，记几次后系统自己就学会了。

## 查历史记录

### 在事件内查

进详情页，往下滚就是完整时间线。每条显示：

- 具体日期时间
- 距上次多久
- 距今多久
- 你写的备注
- 照片缩略图

顶部还有统计：累计次数、平均间隔、判断基准。

### 全局搜索

首页搜索框，可以搜：

- 事件名
- **备注内容**
- 分类标签

比如搜「血常规」，所有备注里提到它的就诊记录都会出来。
**这是回答「医生问上次什么时候」最快的方式。**

### 全局时间线

顶栏的时钟图标。所有事件混在一起按时间倒序，按月分组。
适合回答「上个月我都干了些啥」。

### 年度回顾

设置 → 年度回顾。可以切换年份，看到这一年每件事各做了几次。

## 备份

> ⚠️ 数据只存在手机本地。**卸载应用或清除应用数据会全部丢失。**
> 建议每月导出一次。

设置页有三个导出选项：

| 格式 | 内容 | 用途 |
|---|---|---|
| **ZIP（推荐）** | 数据 + 照片 | 换手机、完整迁移 |
| JSON | 只有数据 | 快速备份、体积小 |
| CSV | 表格 | 用 Excel / WPS 打开做分析 |

导出后会让你选保存位置（建议存到微信文件传输助手，或者网盘）。

**导入**：设置 → 导入备份 → 选文件。
导入是**合并**模式，不会覆盖你现有的数据，同名事件的记录会去重合并。

应用本身也会在每次修改后自动保留最近 4 份本地备份，
但这些备份存在应用私有目录里，**卸载时同样会丢**，不能替代手动导出。

## 常见问题

**Q：为什么没有提醒通知？**

这是刻意设计的。这个应用定位是「需要确认时主动打开查看」，
而不是靠推送逼你做事。提醒一旦变成打扰，人就会直接关掉通知权限。

**Q：数据会不会被上传？**

不会。应用不申请网络权限（`INTERNET`），代码里就没有联网的能力。
无广告、无统计埋点、无账号体系。

**Q：能换手机迁移吗？**

可以。老手机导出 ZIP → 传到新手机 → 装应用 → 设置 → 导入备份。
照片会一起过来。

**Q：误记了一笔怎么办？**

进详情页，找到那条记录，点右边的 ✕ 删除。

**Q：事件建错了想改名？**

进详情页 → 右上角 ⋮ → 编辑事件。改名、换图标、改间隔都在这里。

**Q：某个事件不想用了，但记录想留着？**

用「归档」而不是「删除」。归档后不在首页显示，但数据还在。

**Q：新版本装不上怎么办？**

不应该发生 —— 仓库里提交了固定的签名密钥，各版本签名一致，可以直接覆盖安装。
如果确实提示签名不一致，说明你装的是别处编译的版本，卸载重装即可（记得先导出备份）。

## 拿到 APK 之后

在 GitHub 仓库的 **Actions** 页面，点进最新的那次运行，
页面底部 **Artifacts** 区域点击 `生活手记-debug-apk` 下载。

下载的是 zip 包，解压出 `app-debug.apk`，传到手机安装。

**正式版本**：Actions 页面左侧选「编译 Release 包」→ Run workflow。
产物文件名带版本号（如 `生活手记-v1.0.0.apk`），
勾选「自动发布」会同时打 tag 并生成 Release。
对外分发前建议先在 Secrets 里配好专用签名密钥，详见仓库 README。
